SECURITY NOTE
The requested login model is name-only. It is suitable as an internal convenience/access workflow, but it is NOT strong identity authentication on a public Internet site. Anyone who knows an authorized name can impersonate that person. For true production identity/security, move to Firebase Auth accounts (email/OTP/SSO) and server-enforced roles/custom claims. The current Firestore rules require Firebase authentication but anonymous authentication does not prove the entered display name.
