R&D TRACK v108 - Responsive update

For your existing Firebase/Vercel deployment:
1. KEEP your existing firebase-config.js with the real Firebase values.
2. Deploy the complete extracted folder, including responsive.css, responsive.js,
   kpi-chat.js and kpi-pdf.js. Do not deploy a ZIP as the site root.
3. Keep index.html and all linked JS/CSS files in the same directory.
4. Commit and push the updated files, then wait for the Vercel deployment.
5. Hard refresh each existing browser once (Ctrl + Shift + R).

No database migration, new Firebase project, security-rule change, or browser
library is required by this responsive update. Existing saved data is retained.

Checks (Node.js):
  node verify.js
  node verify-responsive.js
  node verify-task-access.js
  node verify-live-sync.js
  node verify-project-schema.js
  node verify-kpi-chat.js

The mobile navigation drawer supports outside click, Escape and keyboard focus.
KPI filters stay in one horizontally scrollable row on narrow screens.
Large tracking tables scroll inside their own container; chat keeps its composer
visible as the available viewport changes.

Structured data is stored in Firestore. Preserve your existing real Firebase
configuration; the bundled firebase-config.js is a setup template.
